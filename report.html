1. Objective

The objective of this assignment is to transform our custom PC e-commerce web application (AsnkiPC) into a dynamic, highly interactive client-side experience. The project demonstrates core and advanced JavaScript concepts including:

  • DOM Manipulation & Theming: Dynamic element selection, content updates, and a persistent Day/Night theme switcher using CSS custom properties.
  • Event-Driven Architecture: Handling button clicks, modal dialogues, interactive star ratings, and accordion toggles without page reloads.
  • Advanced Data Structures & HOFs: Structuring data through JavaScript objects with methods, managing array collections, and utilizing higher-order functions (filter, map, forEach) to render content dynamically.
  • Procedural Audio Synthesis: Utilizing the browser's native Web Audio API (AudioContext) to generate interactive sound effects without external audio files.
  • Event-Triggered Animations: Smooth 3D transformations via style.transform, interactive hover states, and dynamic floating toast notifications.
  • Robust Form Validation: Enforcing boundary conditions, preventing negative or zero budget entries, validating RFC-compliant email formats, and ensuring password security.

Key Code (js/rating.js):

function setRating(tier, value) {
  var stars = document.querySelectorAll('.rating[data-build="' + tier + '"] .star');
  stars.forEach(function (star, index) {
    if (index < value) {
      star.classList.add('is-active');
      star.setAttribute('aria-pressed', 'true');
    } else {
      star.classList.remove('is-active');
      star.setAttribute('aria-pressed', 'false');
    }
  });
}

3.1 Objects, Arrays & Higher-Order Functions (js/reviews.js)

Goal: Model real-world customer reviews using JavaScript objects with encapsulated methods, and use functional programming methods (filter, map, forEach) to render cards dynamically.

Implementation steps:

  1. Created reviewsData — an array of objects. Each review object contains properties: author, build, buildName, rating, date, comment, plus a method getStars():
  2. Implemented Higher-Order Functions:
    • .filter(): Filters customer reviews according to the selected category (e.g. "All", "5 Stars", "Starter", "Pro", "Ultra").
    • .map(): Transforms filtered review objects into responsive Bootstrap HTML card markup.
    • .forEach(): Iterates through the generated markup collection and dynamically appends cards into #reviews-container.
  3. Added filter buttons with active state switching that triggers re-rendering on the fly.

Figure 3: Verified Customer Reviews dynamically rendered from an array of objects using filter(), map(), and forEach().

Key Code (js/reviews.js):

function renderReviews(filter) {
  container.innerHTML = '';

  var filtered = reviewsData.filter(function (item) {
    if (filter === 'all') return true;
    if (filter === '5') return item.rating === 5;
    return item.build === filter;
  });

  var cardsHtml = filtered.map(function (item) {
    return (
      '<article class="card review-card p-3 p-lg-4">' +
        '<div class="d-flex justify-content-between align-items-center mb-2">' +
          '<strong class="fs-5 review-author">' + item.author + '</strong>' +
          '<span class="badge bg-success">' + item.buildName + '</span>' +
        '</div>' +
        '<div class="text-warning fs-5 mb-2">' + item.getStars() + '</div>' +
        '<p class="mb-3 review-comment">' + item.comment + '</p>' +
        '<small class="review-date mt-auto">' + item.date + '</small>' +
      '</article>'
    );
  });

  var wrapper = document.createElement('div');
  cardsHtml.forEach(function (cardString) {
    wrapper.innerHTML = cardString;
    container.appendChild(wrapper.firstElementChild);
  });
}

3. Challenges Encountered and Solutions

  1. Challenge: Git Merge Divergence during Team Collaboration
    Problem: While finalizing Task 3 locally, another teammate pushed commit 4e5f5a1 to origin/main, causing git push to be rejected.
    Solution: Successfully ran git pull --rebase, resolved a minor script-inclusion conflict in catalog.html, and safely reapplied our local commit cleanly without creating merge noise.
  2. Challenge: Dark Mode Contrast Conflict with Bootstrap Defaults
    Problem: Bootstrap 5's .card class defaulted to dark gray body color (#212529), making author names and dates nearly invisible against our custom dark theme background.
    Solution: Refactored the card markup to use dedicated semantic classes (.review-author, .review-comment, .review-date) tied to CSS custom properties (var(--text) and var(--text-dim)), ensuring optimal contrast in both Dark and Light themes.
  3. Challenge: Bypassing HTML5 Constraints via JavaScript Submit Interception
    Problem: Because e.preventDefault() cancels native browser validation on submit, the HTML5 attribute min="899" on the budget field was ignored, allowing negative numbers to pass through.
    Solution: Added explicit JavaScript validation parsing parseFloat(budgetInput.value), verifying that any non-empty entry satisfies num >= 899, and dynamically appending Bootstrap's has-validation container feedback.
  4. Challenge: Modern Browser Autoplay Policies with Web Audio API
    Problem: Browsers block audio contexts from playing until the user has directly interacted with the document.
    Solution: Lazily instantiated AudioContext and added a state check invoking audioCtx.resume() on the first user click event.
